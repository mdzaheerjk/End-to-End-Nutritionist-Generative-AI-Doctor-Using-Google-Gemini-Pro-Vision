

# Gemini Health — Nutritionist AI (Streamlit + Google Gemini Vision)

A lightweight Streamlit app that uses Google Gemini (Vision + Text) to analyze photos of meals and provide per-item calorie estimates, serving sizes, a total-calorie tally, health rating, and healthier alternatives.

Built for quick experimentation and demos: upload a meal photo, optionally add context, and let Gemini analyze the plate.

Features
- Simple Streamlit UI to upload an image and optionally add text context.
- Calls Google Gemini (via google-genai) with a nutritionist prompt to:
  - Identify foods on the plate,
  - Estimate per-item calories and serving sizes,
  - Compute total calories,
  - Provide a health rating and suggestions.
- Minimal requirements so you can run locally in seconds.

Demo (local)
1. Clone the repo
2. Install dependencies
3. Run the Streamlit app
Commands:
```bash
git clone https://github.com/mdzaheerjk/End-to-End-Nutritionist-Generative-AI-Doctor-Using-Google-Gemini-Pro-Vision.git
cd End-to-End-Nutritionist-Generative-AI-Doctor-Using-Google-Gemini-Pro-Vision
python -m venv .venv
```

Quick start
- Open the app in your browser (Streamlit will show the URL).
- Enter your Gemini API key in the sidebar (the app prompts for it).
- Upload a food image (jpg/png).
- Optionally add an extra instruction in "Additional Prompt".
- Click "🍽 Tell me the Total Calories" to see the nutrition analysis.

Configuration & prerequisites
- Python 3.10+ recommended
- Requirements:
  - streamlit
  - google-genai
  - Pillow
- Gemini API Key: The app expects you to paste your Gemini API key into the sidebar at runtime. For secure usage in production, see "Security & privacy" below.

How it works (runtime summary)
- The Streamlit front-end collects the API key, optional user prompt, and an uploaded image.
- The app constructs a nutritionist prompt and calls google.genai.Client.models.generate_content with these contents:
  - the nutrition prompt,
  - the image (PIL image object),
  - the optional user text.
- The model (currently `gemini-3.5-flash` in app.py) returns text which is shown to the user.

Expected prompt (the app sends the following prompt to Gemini)
```text
You are an expert nutritionist.

Analyze the uploaded food image carefully.

For every food item:
1. Identify the food item.
2. Estimate the calories.
3. Mention the approximate serving size.

- Total Calories
- Whether this meal is Healthy, Average or Unhealthy

Format:

1. Food Item - Calories
2. Food Item - Calories
3. Food Item - Calories

Total Calories:
Health Rating:
Suggestions:
```

Customization tips
- Change model: edit the model name in app.py (line where generate_content is called). Example: use a different Gemini model if you have access.
- Improve accuracy: adjust the prompt to request serving weights, confidence intervals, or to ask for macronutrients.
- Secure key injection:
  - Use Streamlit secrets or environment variables instead of typing the API key in the UI. Example tiny change:
    ```python
    import os
    api_key = st.sidebar.text_input("Enter Gemini API Key", type="password", value=os.getenv("GEMINI_API_KEY", ""))
    ```
  - Or use `st.secrets["GEMINI_API_KEY"]` for Streamlit Cloud deployments.

Security & privacy
- Do NOT commit API keys to source control.
- Uploaded images may contain personal data — be mindful before sharing or hosting.
- If you deploy this app, ensure HTTPS and store secrets safely (platform secrets manager or environment variables).

Limitations & medical disclaimer
- This app provides approximate calorie estimates generated by an LLM — it should not be treated as medical advice or a substitute for a dietitian or physician.
- Visual calorie estimation is inherently imprecise: portion size, cooking method, and hidden ingredients can change calorie counts dramatically.
- Use for education and experimentation, not clinical decision-making.

Troubleshooting
- If the app errors when calling Gemini:
  - Verify API key and that your account has access/credits to use the chosen model.
  - Check dependency versions: try recreating the venv and reinstalling requirements.
- If images are large, Streamlit/GenAI calls may be slow; try resizing before upload.

FAQ (short)
- Q: Can this identify beverages or mixed dishes?
  A: Results vary; the model does its best but accuracy decreases with complex mixed dishes.

Repository overview (concise)

## What this is
A small Streamlit demo that uses Google Gemini (vision + text) to analyze food photos and produce per-item calorie estimates, serving sizes, a total calorie tally, and diet suggestions — intended for experimentation and demoing Gemini's vision + reasoning capabilities.

### Stack
- Language(s): Python (100%)
- Framework / runtime: Streamlit app
- Notable libraries: google-genai (Gemini client), Pillow, Streamlit

## How it's organized
```
.vscode/        # optional editor settings
app.py          # Streamlit UI and Gemini call (main app)
requirements.txt # dependency manifest
LICENSE         # MIT license
README.md       # (this file)
```

How it fits together:
- app.py is the single entry point. Streamlit gathers (API key, uploaded image, optional text), then calls google.genai.Client.models.generate_content with [prompt, image, user_input]. The returned text is displayed as the "Nutrition Analysis". The prompt and model choice control output format and quality.

## How to run it
Shortest path:
```bash
git clone https://github.com/mdzaheerjk/End-to-End-Nutritionist-Generative-AI-Doctor-Using-Google-Gemini-Pro-Vision.git
```

Required env/secrets:
- Gemini API Key (entered in the app sidebar). For production, set GEMINI_API_KEY env var or use Streamlit secrets.
